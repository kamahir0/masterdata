# Current Objective

## Objective

2026-10-22 Human requestに基づき、MasterDataのDesktop / Browser共通GUIを現代的なIDEのworkbenchへ刷新する。VS Code Modern UIとJetBrains Islandsの公式説明・新旧画像を比較し、主要領域を余白・背景階層・角丸のある面で分け、選択file tabと編集内容をつなげる。既存のコンパクトさ、緑accent、豊かな編集操作とMotionを活かす。

## Completion boundary

根拠・設計判断・acceptanceの仕様化と別pass review、自律承認可能な範囲の実装、改修前後の実画面比較、Light / Dark・通常 / 狭幅・Explorer・多数tabs・大きな表・nested・Problems・設定の視覚確認、Desktop / Browserの代表操作と回帰検証、self-review、workspace / whitespace check、通常commit / push、必要なCIの成功確認と結果報告。

## Non-scope

データ形式、保存・復旧、UndoモデルやBuild / Publishの変更、表のセルのカード化、過剰な余白、無関係な大規模refactor、対応Browserの拡張、Unity Editorの起動。

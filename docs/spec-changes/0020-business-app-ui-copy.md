# 業務ツールとしてのUI文言の統一と過剰なスローガンの排除

Status: Approved
Approval mode: Agent-autonomous
Basis: 2026-10-22 Humanの指示「ポエミーな文章を禁止する。これは業務アプリだから。」。別passでintent fidelity、業務アプリとしての自然さ、既存機能への影響、検証可能性をreviewし、Blockingなし。Human gate: None within delegated scope。

## 根拠と意図

- Human Requirement: 「ポエミーな文章を禁止する。これは業務アプリだから。」（2026-10-22）
- 背景:
  ゲームのマスターデータ編集を行う業務アプリケーションとして、実務作業に不要な情緒的スローガンや過剰なキャッチコピー（「世界をつくる」「YOUR DATA, YOUR WORLD」「思いついたその場から」「つながりまで、見える。」など）が配置されていた。これらを排除し、機能と状態を平易かつ正確に伝える業務ツールに適した表現へ改める。

## 変更内容 (Agent Decision)

### 1. ウェルカム画面の文言刷新
- 英文アイキャッチ（`YOUR DATA, YOUR WORLD`）を削除。
- 見出し（`データから、世界をつくる。`）をツール名 `MasterData` へ変更。
- 説明文（`アイテムも、クエストも、そのつながりも。 構造を理解するエディタで、思いついたその場から。`）を、ツールの実務機能と操作案内（`表と型定義を直接編集するマスターデータ管理ツールです。プロジェクトを開くか、新規作成して編集を開始します。`）へ変更。
- プレビューカードのヘッダータイトル（`冒険の道具箱`）を `テーブル編集プレビュー` へ変更。
- プレビューカードのフッター（`つながりまで、見える。`）を `外部キー参照・型定義・値の整合性を管理` へ変更。

### 2. タイトルバーの未選択時表示
- プロジェクト未選択時に表示されていた `データから、世界をつくる。` を削除し、未選択時はツール名 `MasterData` のみを表示する（境界区切り線 `brand-divider` も含めて未選択時はプロジェクト名領域を表示しない）。

### 3. リレーションシップ（参照）空状態テキスト
- `クエストの報酬アイテムなど、表同士のつながりを定義できます。` を、機能と目的を平易・正確に表す `表同士の外部キー参照を定義して、関連するレコードを連携できます。` へ改修。

### 4. パッケージ説明文 (`package.json`)
- `構造を理解するゲームデータエディタ` から `ゲームマスターデータ編集ツール` へ簡潔化。

### 5. UI文言ポリシーの明文化
- `docs/specs/desktop.md` にUI原則として「業務ツールとして平易・簡潔・正確な機能説明を用い、ポエミーなスローガンや過剰な演出表現を用いない」ことを追加。

## Acceptance

1. プロジェクト未選択時のウェルカム画面に「世界をつくる」「YOUR DATA」「思いついたその場から」などのスローガンが表示されないこと。
2. タイトルバーにプロジェクト未選択時にスローガンが表示されず、「MasterData」のみが表示されること。
3. リレーションシップの空状態表示に「クエストの報酬アイテムなど」という比喩表現がなく、外部キー参照に関する説明となっていること。
4. 既存のプロジェクト読込・作成・編集機能およびテストがすべて正常に動作すること。

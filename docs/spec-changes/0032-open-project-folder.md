# 既存プロジェクトをフォルダ選択で開く

Status: Applied
Approval mode: Agent-autonomous

レビュー結果: 選択対象は利用者の明示要求と一致する。読込失敗時も現在の編集を保護し、ネイティブ以外からパスを指定する権限を増やさない。Blocking・未決事項・Human gateなし。

Human request（2026-11-13）: ブラウザ版とデスクトップ版で「開く」の選択対象をフォルダに統一する。

デスクトップの「開く」はネイティブのフォルダ選択を表示する。選択フォルダ直下の `masterdata.toml` で既存プロジェクトを読み込み、親や子は探索しない。取消なら現在の画面を保持する。設定の欠落・不正時は対象と理由を表示し、現在の編集を継続できる。

Agent Decision: フォルダから固定名を解決する責務をネイティブ選択の境界に置く。既存の設定ファイル検証、内部起動、CLI、IPC、新規作成の保存先規則を維持する。ブラウザ版は既にこの選択方式を使う。

受け入れ確認は有効なサンプルのオープン、編集中の取消、空フォルダ・不正設定からの復帰と保存。既存データの変換やアクセス権の追加は不要。

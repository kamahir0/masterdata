# フォルダから生成C#の名前空間を決める

Status: Applied
Approval mode: Agent-autonomous

レビュー結果: 祖先ONは兄弟にも波及するため確認時に明示する。既存設定と出力名を維持し、取消・保存・再生成を検証できる。Blocking・未決事項・Human gateなし。

Human request: プロジェクト設定にルート・階層の既定・フォルダ設定を保存する。途中のOFFで名前空間を止め、子をONにする際はOFFの祖先を確認後まとめてONにする。

Agent Decision: 設定は sources からの相対パスに適用し、定義ファイルの場所で決める。データ分割ファイルは型名に影響しない。未指定は Masterdata.Generated と階層OFF。プロジェクト設定で実効名前空間を表示する。親OFFでも子の個別設定を保持し、確認取消はdraftを変更しない。未設定フォルダはプロジェクトの既定を使う。設定対象はパスであり、移動した定義には移動先の設定を適用する。

受け入れ: Battle/Tutorial/Enemyの途中で停止・再開・取消・保存再読込できる。不正な名前は生成前に診断する。生成クラス・型・参照・データベースを実際にコンパイルし、既存プロジェクトも引き続きBuildできる。クラス単位の上書きは対象外。

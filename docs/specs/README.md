[Product Direction](../product/direction.md)は設計の出発点です。具体的な編集モデルと作業シナリオは、選択されたObjectiveで[Specification Workflow](../contributing/specification-workflow.md)に沿って整理します。

新規仕様はこのdirectoryにDraftから作成します。承認後のsemantic changeは`docs/spec-changes/`の提案を経由します。旧リポジトリの仕様一覧やRequirement IDを、新仕様の一覧として取り込みません。

仕様が採用された時点で、この索引へcanonical ownerとstatusを追加します。
